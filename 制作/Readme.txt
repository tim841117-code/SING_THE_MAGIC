・操作、説明

1.TitleとGame over時、Zキーを押すと、次のシーンに進みます。

2.方向キーでキャラクターを動かします。

3.Xキー で作った魔法を使います。
魔法:
ファイアボール	前方に攻撃します。(色の違う音符を3種類集めると使用できます)
魔紋		魔紋を作って、魔紋の中に立つと、ファイアボールの条件を無視して連発できます。（音符で 3×3 の円を作ります）

4.PlayerがMonsterに当たる、またはMonsterが村に着くと、Game overになります。

5.Monsterを倒すと、10点もらえます。Game over時、画面に得点が表示されます。


・ゲームのポイント

1.動くと、元の場所に音符と音楽が出ます。

2.UIの楽譜を見て、音符を組み合わせて魔法を使いましょう！

3.魔法はただのスキルではなく、音符の順番を考えて組み合わせて使います。本当に詠唱しているようになります。
